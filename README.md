# Camomile (Ромашка)

Личная операционная система для человека и его ИИ-помощника: папка с обычными текстовыми файлами, в которой помощник помнит вас, ваши дела и ваши решения — и растит это вместе с вами.

Это новая, переработанная версия. Упаковка, понятное описание и знакомство с системой — в работе (сентябрь 2026).
