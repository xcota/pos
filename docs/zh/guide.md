# 洋甘菊使用说明：每个词怎么用、文件夹里有什么

_第 2 版 · 2026 年 9 月_

> **开始之前。** 看这篇之前，你手上应该已经有洋甘菊了：下载下来、压缩包解开，而且在 Claude Code 里打开过——Claude Code 是 Anthropic 公司的程序，它读的就是这个文件夹。还没弄好的话，README 里写了一步一步该点哪儿。
>
> **以后不管哪儿出了岔子，你就把屏幕上看到的照直说一遍——他看的是同一个文件夹，大部分毛病他自己就能修。**

**要花多少钱。** 洋甘菊本身不要钱。用 Claude Code 得有 Anthropic 的 Claude 付费订阅——Pro 是便宜的那档，够用；眼下多少钱，Anthropic 自己的官网上写着。要花的钱就这一笔。

**下面这两个说法，后面会一直用到。**

- **打开文件夹**，在这篇里的意思是：在这个文件夹里把 Claude Code 开起来——就是 README 里那两行：`cd` 加上你的文件夹，然后打 `claude`。不是在桌面上双击那个文件夹。
- **卡片**，是他拿给你看的一张东西，说的是你生活里的某一个方面：带编号的几行，写着他听到了什么，你读、你改。没有一个空格要你自己填。

**怎么停下来。** 他回得太长，按 `Esc` 就打断他。想整个关掉，打 `/exit`。你已经跟他讲过的东西都存好了——下次打 `/start`，他从同一个地方接着走。

你其实一个词都不用打。全程用大白话跟他说，洋甘菊照样能用——一开头他自己看一眼那份记录，聊完在后面添几笔。下面这些事，用平常的话说也都行；那四个短词只是省得你多打字。一个都不学，也不缺什么。

这一篇是留着你想刨根问底的时候看的：每个词到底管什么、文件夹里到底放着什么。

## 第一部分：你要打的那些词

值得知道的就四个。就打在你平时打字的那一行里，回车。打错了也坏不了什么——换成大白话说同一件事（“把这次对话存一下”），结果一样。

### `/start`

**什么时候用。** 文件夹刚解开压缩包、头一回用的时候，打一次——中途断了想接着走，再打一次。

**你要打什么。** `/start`（不带斜杠打 `start` 也行）。

**一步一步会发生什么。**

1. 他先问候你，问你想让他怎么称呼你，再用几句话说清接下来是什么：三段讲述、十五分钟左右、每个方面给你一张卡片让你改，然后他给你把那套文件建起来。七个方面是：自我成长（学到什么、长进多少）、活力（身体和精力）、环境（身边的人和住的地方）、财富（对你来说什么算够）、休息、事业，还有资产（钱和东西）。你随时可以停，而且他一次都不会让你给自己打分。
2. 你第一句回答是什么样，他就往什么样上学——你说哪种话、你怎么叫他、话多话少、写列表还是写整段。
3. 一个“要不要”的问题：要不要让他按意思去找你的记录，而不是只能照你当时写的原词找？（你问“我在哪写过没力气”，他能找到那条写着“每天早上像散架了”的记录。）要付出什么，他先说在前头：下载一次，大概 300 兆；占地方大概一个 G——差不多两百张照片。现在说“不要”也行，以后随时说一句“把按意思搜索打开”。
4. 这一步他不用问你：你记录的每一个旧版本他都替你留着，写过的东西丢不了；他还会建一个叫 `inbox` 的文件夹（就是“收件箱”），你想让他读的文件，丢进去就行。
5. 三段讲述，一段一段来——他问，你答，他再问下一段：昨天一天，从起床到睡觉；最近这一个月；今年学到了什么。每一段都一字不动地存下来。
6. 然后每个方面一张卡片，你按编号改：“第 3 条不对，实际是……”。你光说一句“对”，只算认了你自己原话那几行；他自己琢磨出来的那些，你没按编号回过之前，都还算猜测。某个方面你要是讲得够多，他可能在那张卡片最后放上他自己的一个数，外加他有多大把握——那是他的看法，从来不是让你自己打的分。
7. 头两张卡片你改完了，他就开始建你的那套文件。然后他会请你把他关掉再打开一次——整个过程里，你唯一要自己动手的就是这一下。打 `/exit`；然后照 README 那两行来：`cd`，空格，用鼠标把你的文件夹拖到窗口里，回车——再打 `claude`，回车。剩下那五个方面的卡片，重开之后接着来。

**你会看到什么。** 就是一场普通的对话：没有技术词，不会给你甩一串文件地址，也不会蹦出报错。卡片长这样：

> **事业**
> 1. 你说：“铺子把我一早上全占了——七点我就站在柜台后面。”
> 2. 你说：“包装那家供货的我自己接过来了，不然没人去催他们。”
> 3. 我在你的文件里看到：跟那家供货的，你的期限是周五。
> 4. 我觉得：进货、看店、记账全在你一个人身上，没人能分担。
>
> 我不知道：你是想把铺子做大，还是只想做得省心点。
>
> 我听到的是：晚上比早上还难熬——对吗？
>
> 这个方面在我看来：一个人的生意，绷到头了，撑得住，但一点余量都没有。比较有把握——三段讲述里都提到了。

你回一句“第 4 条不对，账是我妹管的”——或者干脆说一句“对”。

**他会写什么。** 你的“我是谁”这个文件，你自己的话和他的猜测分开放 · 你的目标 · 你的首页，带七个方面 · 他的记忆目录 · 各个方面的卡片 · 你讲的那几段，一字不动 · 你记录里关于你的一页 · 他给自己写的那张说明书——照着你的脾气写的 · 还有他看出来、你自己不容易察觉的那些地方，写成他以后要守的规矩。


### `/session-save`

**什么时候用。** 一场值得留下的对话聊完的时候；或者聊得太久了——这个他自己盯着，该存了会提醒你。

**你要打什么。** `/session-save`，后面可以再给它起个名——“把这次存成供货商那场”——以后好找。

**一步一步会发生什么。**

1. 他先把这场对话从头过一遍，看的是他自己：你在哪儿纠正了他，你看重什么，他哪儿没做到。
2. 你要是纠正了他跟你说话的**方式**，他会给你“我是谁”这个文件里的「怎么跟我打交道」那一段想好一两句话——一句一句问你行不行。你不吭声，他一个字都不写。
3. 七个方面里要是冒出了新情况，你说的原话进你讲的那几段，那个方面的卡片上再添一行——不重做这个方面，也不再把卡片端出来。
4. 他把上次存完之后还没落到纸上的东西归拢一遍，专挑那些只在聊天里说过、文件里还没有的活儿；真正新的东西单开一页。
5. 他把“停在哪”改成最新的，往今天的记录里添两三行，再写一张五百字以内的交班条：做完了什么、还剩什么、哪几个文件要紧、下回从哪儿接着走。
6. 他把这会儿的文件夹整个存一份，留着当旧版本。然后，要是离上次隔得够久了，他会用一句话问你两件事里的一件：要不要整理记忆，或者要不要把他自己出的岔子过一遍。两件都得你点头才做。

**你会看到什么。** 一小段报告，说存了什么，外加那一两句等你说行不行的话。

**他会写什么。** 你的“我是谁”这个文件（就那一段） · 你讲的那几段 · 一张方面卡片 · 今天的记录 · “停在哪” · 新开的页 · 他记下的教训和他出过的岔子清单 · 一张交班条。

**例子。**

> **你：** 把这次对话存一下
> **他：** 存好了：换供货商这件事、你为什么换、两个报价、周五是最后期限。“停在哪”那儿写着：你在等他们回话。
> **他：** 有一句等你点头——你有两回让我别老追着问。要不要写下来：“除非我开口要几个选项，不然别追着问”？
> **你：** 行
> **他：** 写上了。还有：我的记忆该整理了——现在整，还是回头再说？


### `/recall`

**什么时候用。** 你想找以前写过的东西，可想不起当时是拿什么词写的了。

**你要打什么。** `/recall` 加上你的问题，用你自己的话问。

**一步一步会发生什么。**

1. 他先看一眼你这儿有没有开按意思搜索——悄悄看，不会停下来问你要不要开。
2. 开了，他就按意思找：给你找回来几条最像的记录，每条都带上对上的那一段，还有里头的几句原话。
3. 没开，他就照你当时写的原词去找，再用一句大白话跟你说一声（一场对话里只说这一次）：按意思搜索还没开，想要就说一句。要是开了却出了毛病，他不吭声，直接改回按原词找——你绝不会看到满屏带文件地址的报错。
4. 光甩给你一串名字不算回答——所以他会把最像的那两三条打开，把相关的那段念给你听。

**他会写什么。** 你的东西一样都不写——他只读你的记录。（按意思搜索自己会在它那本词典旁边记个流水账。）

**例子。**

> **你：** `/recall` 我在哪写过早上像散架了
> **他：** 最像的是你讲昨天那段：“六点醒的，感觉像被车撞过。”另外七月那张活力卡片上还有一行——早上是一天里最难受的时候，那个月你把九点以后吃东西给停了。


### `/reflect`

**什么时候用。** 大概每三天一次。这个他自己算，用一句话问你，你点头他才做。你也可以随时叫他做。

**你要打什么。** `/reflect`。

**一步一步会发生什么。**

1. 他先把这些归拢到一处：最近三到五天的记录、最近定下的事、他记下的教训、最近几次存的东西，还有他出过的岔子清单——那是他自己抓到的错，一条条记着，免得同样的事再犯一回。
2. 主要还是把聊天本身重看一遍：你说了什么，他答了什么，你们俩在哪儿卡住了。
3. 关于你：你看重什么、烦什么，你想要什么但没说出口——每看出一条，就写成一句话，建议加到你“我是谁”这个文件里。关于他自己：哪儿自作主张干了你没让干的事，哪儿话还没听明白就先动手，哪儿给的东西比你要的多得多，哪儿让你干等着——每一条都记进他出过的岔子清单。
4. 他把教训捋出来，说说该改什么，再看看你的目标还作不作数，最后把这一遍写成一份短报告存起来。
5. 然后他用你平时说话的那种话，念三到五句大白话给你听：他觉得自己摸清了你喜欢别人怎么跟你说话、这方面他还有什么不知道，还有那一两处他不会再犯的岔子。他什么都不问你——这是面镜子，不是问卷。

**你会看到什么。** 一份很短、也不好听的报告，然后是那几句话。他自己的规矩是：说实话，失手的地方不许往好里粉饰。

**他会写什么。** 他记下的教训 · 他出过的岔子清单——同一条冒出来三次或者更多，就写进文件夹的规矩里，让它再也发生不了 · 你的目标（前提是你的时间安排变了） · 一份带日期的报告 · 这一次是哪天做的，好算下回什么时候再做。

**例子。**

> **你：** `/reflect`
> **他：** 三天里两处失手：周二你只要一个数，我给你摆了张表；周三你问我事，我先反问了你三个问题。
> **他：** 我自认摸到的：先给短答案，别给表格、除非你开口要，还有你宁可听见“这块缺东西”，也不要我瞎猜。我还不知道的：我不同意你的时候，你要不要我顶回去。
> **他：** 我不会再犯的两条：不给你没要的表格，先答再问。


### 他自己会开口问的两件事

两件，各一句话，都等你点头。你每次打开文件夹，他最多开口一次。

**整理记忆。** 得两头都够上：离上一次过了一天，**而且**这中间你大概打开过五次文件夹。够上了，他会说一句：他的记忆要花几分钟整理一下，现在做不做？下面是六步：

1. 动手之前，他先把已经写下的东西看一遍。
2. 他把最近这几天的东西归到一处，再挑出那些已经过时的说法。
3. 他把自己记重的并到该去的文件里，不留一堆差不多重复的；把“昨天”换成真正的日期；把他发现是错的那些删掉。
4. 他把自己那份记忆目录缩短。
5. 他把按意思搜索重新过一遍。
6. 他报一下改了什么。

你自己的话他一个字都不碰：你讲的那几段，还有卡片上「你说」那几行，按他自己的规矩就是碰不得的；他只收拾他自己写的东西，而且旧版本都留着。你说“回头再说”也不会坏什么——你存对话的时候他会再问，下次打开文件夹再问。你要是压根不想让他问，就说“以后别再问我要不要整理”（或者“这事别再问我”）：他会把这句写进你“我是谁”这个文件，从此以后你不叫他，他就不整理。

**看看他自己出的岔子。** 大概每三天一次——就是上面 `/reflect` 那一套，问法一样：一句话，你点头才做。


### 还有别的词，想用再用

下面这七个，一个都不用记——每一样都能用大白话跟他说。

**`/ingest`** —— 把一段录音整理稿、一份聊天记录、笔记，或者一条 YouTube 链接，变成你记录里的一页一页。视频要用一个不要钱的小程序，叫 yt-dlp：你问一句“我这儿有 yt-dlp 吗”，他会去看，再带着你把它装上。视频没有字幕的话，他绝不会编一份稿子出来——他会让你自己把稿子贴进来。

**`/query`** —— 一个问题要把好几条记录串起来才答得了，用它。他直接给你答案，每句话是从哪条记录来的都标上，然后把答案存成一页。

**`/graph-add`** —— 给一个人、一个项目或者一个决定单开一页。要是原来有条记录跟这个对不上，他把两个版本都留着，并且告诉你。

**`/self-check`** —— 给这个文件夹做个体检：八样东西各打个分，满分十六——刚建起来的文件夹，满分算十四，因为“项目”那一项还不算。他把毛病从最要紧的往下排，每条都说怎么修。

**`/lint`** —— 给你的记录做个体检：没有别的页连过去的页、一个月没人核对过的说法、同一个数出现了两种写法。他只报给你，不会闷声替你改。

**`/enable-modules`** —— 打开一个附加包（就是多教他一门专门的本事）。空着的地方他才放几个起步的文件，你填过的地方绝不覆盖。这个词不用记：说一句“把健身那个附加包打开”就行。

**`/compress`** —— 把一场长对话压成大概一页，然后再回头查一遍：文件名、数字、人名有没有在路上丢掉。


### 他自己用的词——你可能会在他的回话里瞄到

这些你从来不用打；只是有时会在他的回话里晃一下，所以这儿说一句都是什么。

- **`/session-start`** —— 平常的开场。你一打开文件夹，后台那三个自己跑的小程序里，有一个就顺手把这事办了。
- **`/dream`** —— 就是整理记忆。他问你，你说“好”；这个词你根本用不着。
- **`/svoboda-profiler`** —— 第一场对话里问你要三段讲述的，就是它管的那一段。（*Svoboda* 是俄语“自由”的意思，就是个名字。）你说一句“事业那块再走一遍”，叫的也是它。
- **`/vault-scaffolder`** —— 给你把那套文件建起来的那一部分。`/start` 会替你叫它。

## 第二部分：文件夹里有什么

全是普通的文字文件——你电脑上自带的那种记事本一类的小软件，随便哪个都打得开。

| 名字 | 里面装什么 | 你能改吗？ |
|---|---|---|
| `HOME.md` | 你的首页：你要往哪儿去、七个方面、手头在做什么。 | 能 |
| `CLAUDE.md` | 助手的那张说明书，你每次打开文件夹他都要看一遍。 | 别动——再建一遍文件夹的时候，这个会被整个重写 |
| `MEMORY.md` | 他的记忆目录——一个话题一行，写着那条记录真正在哪，像书最后那几页的索引。内容本身都在别的文件里。 | 小心点改 |
| `README.md`、`README.zh.md` | 给头一回来的人看的门面，英文和中文各一份。 | 能 |
| `AGENTS.md` | 第二张说明书，内容一样，是给 Claude Code 以外的别的 AI 程序看的——跟 `CLAUDE.md` 得靠人手动保持一样。 | 小心点改 |
| `LICENSE` | 法律条文（AGPL v3）：随便用、随便改。 | 别动 |

## 第三部分：幕后是怎么回事（想知道再看）

### 每次你打开文件夹

你一个字还没打，他已经把关于你的一小块东西读完了：你停在哪、“该往哪儿使劲”最上头那几条、今天记录的最后几行、最新的三张交班条。所以他从来不问你是谁。要是这个文件夹还没弄起来，他就只回你一行字：打 `/start`。

他还顺手看看日子：该不该整理记忆了（离上次过了一天，而且这中间你大概打开过五次文件夹），该不该复盘他的岔子了（大概三天）。要是到点了，他会问你一句：现在做不做——一次最多问一件，先问整理，你不点头，什么都不动。你要是跟他说过永远别问，那他一声不吭，等你开口。


### 你说存一下的时候

你看到的是一小段报告，说什么进了记录，外加一两句等你说行不行的话；硬盘上多出来的，就是 `/session-save` 那一节列的那些文件，外加整个文件夹又存了一份旧版本。「怎么跟我打交道」那几行，永远只记你喜欢别人怎么跟你说话——答短点、别用表格、叫我名字。它们从来不记他对你这个人的看法；那些都在方面卡片上。


### 整理记忆，说细一点

你看到的就两样：问你的那一句，还有最后那份最多十五行的报告。中间就是第一部分那六步——有三件事值得说一下。动笔之前他先把已经写下的东西看一遍：没读就下总结，东西就是从这儿开始编出来的；所以他要是读不了，那就干脆不做。要是有一行写着通向某条记录，可那条记录根本不存在，这一行他压根不写。还有，把按意思搜索重新过一遍，只重读改过的那些文件，几秒钟的事——从头建一遍要久得多，可那只有你头一回打开它的时候才会碰上，而且是在后台跑，你该干嘛干嘛。你自己的话从来不碰：你讲的那几段，还有卡片上「你说」那几行，按他自己的规矩就在打扫范围之外——他只收拾他自己写的东西。


### 按意思搜索

他把你的记录切成一段一段，每段都连着它头上的那个小标题，所以你的问题对上的是一段话的**意思**，不是一模一样的词。它找的范围是：你的记录、你每天的记录、报告、你自己讲的那几段，还有 `inbox` 里的任何东西。这些全装在你自己硬盘上多出来的一个文件里，什么都不往外发。它占的地方——文件夹里大概一个 G 的、藏起来的帮手文件，外加文件夹外面留着的那 300 兆下载——都不是你的记录，两处都能删了再建。

它不是一直开着的：你一问，它醒过来，再醒着待半个钟头，好让你下一个问题马上有答案，然后睡回去。从你电脑外面够不着它。


### 核对引用

一张卡片拿给你看之前，上面每一行凡是说这是你的话的，都要跟你自己讲的那几段一个字一个字对过；大小写和标点不算数。词要是不在里头，那就是助手自己的说法，于是这一行改成“我听到的是……——对吗？”。要是这道核对根本跑不起来，这张卡片**就先不拿出来**，等弄好了再说。

这道核对什么都不往外发，英文、中文、俄文都对得上。它要用 Python，大多数电脑上本来就装着——你问一句“我这儿有 Python 吗”，他会去看。没有 Python，「你说」那几行就干脆不放，只留「我在你的文件里看到」「我觉得」和「我不知道」：核不了的东西，绝不冒充成你的话。


### 旧版本，和怎么找回来

每存一次，文件夹都在你自己硬盘上记一笔，用的是一个到处都在用、又不要钱的工具，叫 git；刚下载下来的文件夹一笔都没有，所以第一场对话他会悄悄给你开一本账。要找回来，你用大白话说就行：“把我目标那个文件昨天的样子找回来” · “给我看看这个文件一个礼拜前什么样”。这事他有一套固定的做法：他按日期找到那个版本，先把旧的文字念给你听，让你看清你要拿回来的是什么，你点头了他才把那**一个**文件放回去——绝不动整个文件夹，绝不动你没点名的文件。你原来那一版也留在记录里，所以你反悔也来得及。他要是磨蹭，你就跟他说：这个文件夹自己留着旧版本（git）——用那个。还有一条自己动手的路子，别的全不灵的时候它也灵：三步都写在第四部分“出岔子了”那儿。

### 拷贝、搬家、重来

把文件夹拷一份，东西全跟着走：每一条记录、每一段讲述、每一张卡片，还有旧版本。删了它，你的记录就没了；没有第二份。文件夹你放哪台电脑的哪儿都行，照样能用。有两样住在外面、不跟着走：Claude Code 自己存的那份对话记录，还有按意思搜索下载的那一份——两样都不是你的记录，而且都能重新弄出来。就算把建文件夹那一步再走一遍，你写的东西也不会被清空：目标一字不动地留着，划掉的行还是划着。唯一的例外是助手自己那张说明书 `CLAUDE.md`——那个每次都整个重写，所以你往里头加过的东西，记得另存一份。


### 什么会发到网上，什么留在你机器里

**会出去的。** 你的对话，包括他为了答你而读的你记录里的片段——跟你打进任何 AI 聊天框里的字一样。东西存在你这边，动脑子那部分在 Anthropic 那边的机器上，所以你聊的时候得连着网。只有开了按意思搜索才多一样：那一次 300 兆的下载，而且要付出什么，在你回答之前就跟你说清楚了。

**留在这儿的。** 按意思搜索和核对引用从不离开你的机器。你的记录就是你硬盘上的普通文件——没有什么存东西的软件，没有我们的机器，哪儿也不用注册。

**绝不写下来的。** 密码、支付密码、密钥、卡号、安全码、短信验证码、钱包助记词、身份证号，绝不进任何文件，就算你自己念给他、还让他存也不写。这是条硬规矩，不是一句保证。只记事情，不记秘密——写“有银行的权限”这种就行。


### 他守的那些规矩

十一条硬规矩。大多数是这么来的：先好言好语提醒过，没拦住，同样的毛病又犯了，才升成硬规矩；只有一条——记录里不写秘密——是一上来就写死的，为的是让早先许下的那句承诺，底下真有一条规矩兜着。头三条什么时候都算数。

1. **先说人话** —— 一样东西是什么、能给你什么，用平常的词讲。
2. **照实报** —— 有什么说什么，不在结果外头裹一层好听的。
3. **记录里不写秘密** —— 任何文件里都不写密码、密钥、卡号、验证码、钱包助记词，你念给他也不写。
4. **问什么答什么** —— 绝不拿旁边那个他更好答的问题来顶数。
5. **先弄明白你到底要什么** —— 答之前、动手之前，先弄明白。
6. **花的力气跟活儿对得上** —— 自己用的工具就是个工具，不是产品。
7. **纠正是永久的** —— 你纠正过一次，就一直算数；你手头在忙的事，你不发话他不动。
8. **正事就是正事** —— 你说了要办的那件事**就是**正事；要不要拐去别的方向，由你开口。
9. **看不见听不着的，不下判断** —— 要看要听的东西，一律退回给你，不去瞎猜。
10. **这个文件夹就在你自己电脑上** —— 它留着旧版本是给你图个方便，不是跟谁签的合同。
11. **文件名要朴素** —— 这是他给自己文件定的一条家务规矩：小写字母、数字、短横和下划线。跟你没关系。


### 附加包（要不要随你）

一个附加包，就是多教洋甘菊一门专门的本事——比方说健身，或者记账。一开始全是关着的，现成的也一个都没带：只带了一个做好的样子货，也关着——你可以打开看看它怎么转，然后照着换成你自己的。问一句“都有哪些附加包”看单子，说“把……那个附加包打开”就开一个。

## 第四部分：照着做

**记住一个人。**
1. “给安娜单开一页——她供包装的，三月展会上认识的。”
2. 他给她开一页，跟相关的东西连上，以后找得到。
3. 要是已经有条记录跟这个对不上，他把两个版本都摆给你看，不覆盖。

**丢个文件给他。**
1. 把文件放进 `inbox` 这个文件夹。
2. 说一句“去 inbox 看看”——你不开口他不会去处理里头的东西，不过搜索是会看里面的。
3. 录音整理稿这类的，你说一句“把这个读进我的记录里”，它就变成你记录里的一页一页。

**“我当时为什么那么定？”**
1. 直接问：“我当时为什么不用那家供货的了？”
2. 他找到你自己那条记录，念给你听——是你的理由，不是他猜的。
3. 想让下回更好找：“把这个决定和理由记一笔。”

**他话太多。**
1. 当场就说：“短点” · “别用表格，除非我要”。
2. 聊完他会把想为这事写下来的一两行摆给你看。
3. 你说行，这个说话方式以后每一场都还在。你不吭声不算同意。

**擦掉关于我的某句话。**
1. 说“把我那一行去掉”，他就把这行挪进你文件里「划掉的」那一段，带上日期：它不再算数，但字还在。想彻底没有，你自己把这行删了。
2. 划掉的行绝不会再放回来；你手动改过的行，绝不会被重写。
3. 想看看都有什么：“把你手上关于我的东西念给我听。”

**我换了台新电脑。**
1. 把整个文件夹拷过去——记录、讲述、卡片、旧版本，都在里头。
2. 在那边装上 Claude Code（Anthropic 的说明：https://code.claude.com/docs/en/setup ），然后跟在家里一样打开文件夹：在那个给电脑打字下指令的窗口里，打 `cd` 再把文件夹拖进来，然后打 `claude`。这几句你要是看不懂，README 里写了一步一步该点哪儿。
3. 你原来开了按意思搜索：“把按意思搜索再打开一次”——一条记录都不会少。

**出岔子了。**
1. 用大白话把你屏幕上看到的告诉他；他看的是同一个文件夹，大部分毛病他自己就能修。
2. 想要个说法：“这个文件夹有哪儿坏了吗？”
3. 最坏的情况，走自己动手这条路，它永远灵：
   1. 把你的旧文件夹改名叫 `camomile-old`。你的记录还在里头，一点不动。
   2. 再下载一份洋甘菊：打开 https://github.com/xcota/pos ，按绿色那个“Code”按钮，选“Download ZIP”（你那边打不开 GitHub 的话，用 https://gitee.com/cotya/pos-starter ），解开压缩包。
   3. 打开新的这个文件夹，说一句：“我的旧文件夹就在这个旁边，叫 camomile-old——把我的记录搬过来。”

**第一场里某个方面我想重来。**
1. 说一句“事业那块再走一遍”。
2. 他只重写那一张卡片，而且是从已有的东西往下改，不是从白纸开始。
3. 你的话先进你讲的那几段，然后那张卡片才改。

**我想给我的项目开一页。**
1. “给新收银机那事开一页”——外加你手上的情况。
2. 他把这一页跟该连的地方连上，还会去看有没有别的页连到它。
3. 等这个项目真长出一堆细节了，你开口要——“把这个项目单独放一个文件夹，带自己的记录”——他就动手给它建一个，名字照这个文件夹里起名的规矩来。
