# Camomile：这是什么、怎么运作、怎么用

_第 2 版 · 2026 年 9 月_

**他自己会做的事：** 每次打开，他先把自己那份记录看一遍（你是谁、上次聊到哪）。每隔几天他会问一句要不要把记忆整理整理，另外还会单独问一句要不要把自己出的岔子过一遍——两件事都得你点头才做。除此之外，你不开口，什么都不会发生。

## 这是什么

Camomile（洋甘菊）是你电脑里的一个文件夹，加上一个会读写这个文件夹的 AI 助手。助手住在 Claude Code 里面——那是 Anthropic 公司的一个程序，要在“给电脑打字下指令”的那个窗口里打开——他不住在文件夹里。这篇东西网上也有一份，你想先看看再决定要不要下载：https://xcota.github.io/pos/ （English · 中文 · Русский）。

平常的 AI 聊天，每次都得从头说起：你是谁、在忙什么、已经定下了什么。在这里，这些都躺在你自己硬盘上的文件里。助手在聊天开头看一眼，聊完在后面添几笔。用得越久他说得越准——不是因为他“变聪明了”，而是因为关于你的记录多了，而且是用你自己的话记的。

**这是给谁用的。** 用过 ChatGPT，又觉得 AI 不该只给一次性答案的人。全程你一行代码都不用写。

换成平常的日子是什么样：你跟他聊要不要把某个供货的商家换掉、为什么换——半年后你问“我当时为什么不用他了”，答案是你自己当时说过的话，不是他现编的。或者你出门两个礼拜回来，问“新收银机那件事我上次弄到哪儿了”——他告诉你，连你当时为什么停在那儿也一起说。

只有那个窗口开着、你在里面打字的时候，他才动。窗口一关，他就没有任何东西在碰你的文件——电脑关掉也一样，你不重新打开，什么都不会发生。

名字来自一幅画面——你想象一朵洋甘菊：你在中间，周围七片花瓣——自我成长（学到什么、长进多少）、活力（身体和精力）、环境（身边的人和住的地方）、财富（对你来说什么算够——是那个感觉，不是数字）、休息（什么能让你恢复）、事业（你在做什么）、资产（钱本身：收入、存的钱、房子、东西、欠的钱）。过日子从来不止一个方面，所以这七样他都记；时间一长就看得出哪一片写得满、哪一片你根本没提过。

## 一步一步会发生什么

### 第一天：装到你电脑上

一共四步，你自己要打的字就四小段——剩下的时间都是等下载。之后他跟你认识的那场对话，再加十五分钟左右。

1. **装 Claude Code** —— Anthropic 公司的程序，要在“给电脑打字下指令”的那个窗口里打开。Mac 上：同时按 Command 和空格，屏幕中间冒出一个搜索框，打“终端”，回车。Linux 上：那个窗口一般也叫终端，从程序列表里打开，或者同时按 Ctrl、Alt 和 T。然后打开 Anthropic 的这一页 https://code.claude.com/docs/en/setup ，找到写着给你这类电脑用的那一行字，选中、复制。点一下刚才那个终端窗口，粘进去（Command 加 V；Linux 上是 Ctrl 加 Shift 加 V），回车，等到字不再往下滚——一两分钟。这件事一辈子只做一次。你得有 Anthropic 的 Claude 付费订阅：Pro 是便宜的那档，开头够用。
2. **下载这个文件夹。** https://github.com/xcota/pos → 绿色的那个“Code”按钮 → “Download ZIP”（这两处都是英文，照着字找就行）。那一页叫“pos”——没错就是这儿，那是同一样东西的旧名字。你那边打不开这一页的话（比如在国内），同一个文件夹在 https://gitee.com/cotya/pos-starter → “克隆/下载” → “下载 ZIP”。双击下载下来的压缩包，旁边就出来一个文件夹，叫 `pos-main` 或者 `pos-starter-master`——就是它，名字怪是正常的。把它挪到“文稿”里，想改名叫 Camomile 也行。
3. **告诉窗口去这个文件夹。** 先把“文稿”打开，让它和那个终端窗口并排摆着、都看得见。在窗口里打 `cd`，空格，然后用鼠标把 Camomile 这个文件夹本身拖到窗口上——是文件夹，不是你下载的那个压缩包——回车。`cd` 的意思是“进到某处”；自己冒出来的那一长串带斜杠的字，是这个文件夹在电脑里的地址，别去改。然后打 `claude`，回车。头一次他会打开浏览器让你登录 Claude 账号——用你买订阅的那个账号登，登完回到窗口。他可能还会问你界面要亮色还是深色，随便选。接着他问你信不信这个文件夹里的东西：答“信”，这是你自己的文件夹。要是窗口回你一句 `command not found`（英文，意思是“没找到这个命令”），把这个窗口关掉，照原样重开一个，再打 `claude`——装之前就开着的窗口，还不知道电脑里多了这个东西。要是还这么回，说明没装成：回第 1 步重做一遍。
4. **打 `/start`**（前面那根斜杠也要打），回车。你需要知道的最后一件事。

成功是什么样：窗口里的字清空，出现一句问候，下面有一行可以打字。从这儿开始就是普通的一来一往打字聊天。

### 第一次对话：他跟你认识

他问你想让他怎么称呼你，再用一小段话说清接下来是什么：三段讲述、十五分钟左右、每个方面给你一张卡片让你改，然后他给你把那套文件建起来——而且你随时可以停。

他一次都不会让你给自己打分。每个方面他写的是他自己的看法——十分里给几分，加上他有多大把握——而且只写你讲够了的那些。那个分是他猜的，是给你改、给你划掉用的，不是给你评级。你自己报个数（“事业我给八分”），他就当成你说的记下来，看法不一样也会说出来；他只是从来不问你要这个数。

他从你第一句回答里就开始学你的样子：你答得短，他就问得短，一次问一个；你的语言、你的口气，包括脏话，你用他也用；你怎么叫他，用名字还是别的叫法；你写列表，他也写列表。

很早他会问你一件要不要的事：按意思搜索。他会先把代价说在前头——硬盘上大概一个 G，下载一次，五到十分钟。你说“不要”，一切照常，只是搜索改成按你写的原词去找。他不会偷偷下载任何东西。你回答的这会儿，他顺手在文件夹里把两样东西弄好：把你记录的旧版本存着，还有一个叫 `inbox` 的文件夹（就是“收件箱”的意思），你以后可以把自己的文件丢进去。

然后是三段讲述，不是填问卷：昨天一天，从起床到睡觉；这一个月——买了什么、后悔什么、高兴什么；这一年学到了什么、跟谁学的。你的话一字不动地存下来，而且只有这些话会被原样引回给你。

每个方面给你一张卡片过目：带编号的几行——「你说」（你的原话；拿给你看之前，他先跟你讲过的内容核对过）、「我在你的文件里看到」、「我觉得」，然后是「我不知道」和「我听到的是『…』——对吗？」。他自己对这个方面的看法放在最后，带上他有多大把握。你按编号改：“第 3 条不对，实际是……”。你光说一句“对”，只算认了「你说」那几行——他的结论在你按编号回它之前，一直算他的猜测。某个方面你几乎没说？那就干脆没有分，只有一句“这个你没说过”——不是零分，也不是“薄弱项”。

过了五个方面，问题往深里走：什么事真的让你火大，你失去过什么到现在还没消化，一个人待着和孤独有什么不一样，对你来说什么是回不了头的，什么让你来劲、什么把你抽干。这些哪一条都可以不答——你说不想说，他就换下一条。父母和小时候是单独一段，同样看你愿不愿意。

至少有两张卡片你点过头或者改过，他才开始建你的那套文件——两张就够，不用等七个方面全齐。不同意完全没问题，改了也算答了；他只是要在动笔之前，至少有两张卡片拿到你的“行”或者你的修改。不然他自己的猜测会在以后每次对话里被当成事实读出来。

然后他写你的文件：你是谁、怎么跟你打交道、你的目标、开头几件事、一张七个方面的总览、一张“该往哪儿使劲”的单子——只列你自己说是窟窿的那些方面，用你自己的话——还有这次对话本身的记录。整个画像都标着“初步的”。而且他不会拿自己打的分去定计划：他给的低分只留在那个方面的卡片里当他的看法，你尽管按编号不同意。

最后他会请你把他关掉再打开一次：打 `/exit` 回车（或者干脆把窗口关了），然后把第 3 步那两行再走一遍——`cd` 加把文件夹拖进来，然后 `claude`。整场里你唯一要动手的就是这一次重开。

快的一遍十五分钟左右。更深的东西不用你另外约一场——它就是在平常聊天里一点一点攒起来的。随时可以停：都写下来了，你回来再打 `/start`，他从同一个地方接着走，不会从头来。

### 以后每次对话

还是照原样打开那个窗口；键盘上的向上箭头会把你上次打的字调出来。什么都不用你再交代一遍。他回话之前先看自己的记录——你是谁、你喜欢别人怎么跟你说话、上次停在哪、今天存了什么——然后从那儿接着走。

聊完你说一句“把这次对话存一下”。他会把做了什么、定了什么记下来，往今天的记录里添两三行，真正新的东西单开一页；要是聊天里顺带提到了七个方面里的某样新情况，就往那个方面的卡片里添一行，用你的话。他不会重新给这个方面打分，也不会再把卡片端出来；整个方面重做一遍，只有你要求才会做。你忘了、直接把窗口关了，文件里已有的东西一样都不会丢——只是今天这一场没记下来。下次说一声，接着走。

### 每隔几天

两件他自己会开口的事，各一句话，都等你点头。

**整理记忆。** 记下的东西越攒越多，有的记重了，有的早过时了。每隔几天他会说记忆要花几分钟整理一下，问现在做不做；你答“好”或者“回头再说”。他动的是他自己那本账：把他自己记重的并到该去的文件里，不留一堆差不多重复的；把“昨天”这种说法换成真正的日期；把你后来纠正过的、他自己那些旧记录删掉；把他自己那份清单缩短，好找得更快；再把按意思搜索重新过一遍，新记下的东西也就找得到了。你自己的话——你讲给他的那些——一个字都不碰，文件的旧版本也留着，什么都能找回来。做完他用几行字报一下改了什么。

**看看他自己出的岔子。** 大概每三天他会问要不要把这几天过一遍——哪儿把你的意思读错了，哪儿做多了，哪儿让你等了——再把教训写下来，免得同样的事再来一次。

### 随时用得上

用你自己的话找旧东西：“我在哪写过早上没力气”。开了按意思搜索，他能找到那条写着“起床像散架了”的记录；没开，他就按你写的原词找，并且老实跟你说一声，只说一次。

问几个月前为什么那么定，答案是那条记录，不是他现编的。想把一天里攒下的东西都给他——想法、链接、文件——说出来就行；文件的话，你自己的文件夹里有个叫 `inbox` 的地方，丢进去然后跟他说“去 inbox 看看”——他不会自己去翻。哪儿让你别扭就纠正他：“短点”、“这事别问我”、“叫我名字就行”。这类纠正只当成跟你说话的规矩留着，绝不会变成关于你这个人的结论；聊完他会把想记下来的一两行摆出来，只留你点头的那些。你没吭声不算同意。

### 绝不会发生的事

他不会先来找你，不会提醒你，不会到点自己干活，不会盯着你。他不会让你给自己打分。他不会不声不响往你电脑上装东西。他不会因为你答了话就夸你，也不会把事讲得像在跟十岁小孩说话。他不会把自己的说法冒充成你的话：在你讲过的话里找不到的引用，会变成“我听到的是『…』——对吗？”。密码、支付密码、密钥（给程序用的那种一长串钥匙）、卡号、验证码、钱包助记词，他绝不往任何文件里写，就算你自己念给他、还让他存也不写。你划掉的一行他不会再弄回来，你手动改过的一行他不会重写。整理记忆和复盘岔子这两件事，没你点头他绝不开始。

## 里面就三样

**记忆——他在两次对话之间记得你。** 就是普通的文字文件：你是谁、你现在在忙什么、你的目标、每天的记录、关于人和项目的页。开头他自己看，聊完你说一句“存一下”。没有什么玄乎的机关，也没有那种专门装数据的系统：用最简单的记事本一类的小软件打开文件，看到的就是普通文字，你自己也能改。

**你的事情——他帮你盯着项目和决定。** 你每件事各有一页，页和页之间互相连着——像一本关于你自己生活的小百科。人、项目、决定、看过的东西的笔记。难定的事让他单独记一笔、带上理由，半年后“我当时为什么那么干”就有答案，不用猜。

**他怎么跟着你调——他记住你的纠正，你说过别做的就不再做。** 这是平常的聊天没有的。你关于“怎么跟你说话”的纠正会记进你自己那个文件里的「怎么跟我打交道」一段，而这个文件每次开头都要重看一遍——所以你今天关了窗口、明天开个新的，那套说话方式不会丢。变的是**说法**，不是内容：该说的难听事实和窟窿他照样点出来，只是按你教他的方式说。文件夹里还带着四十多条已经拆开讲明白的常见毛病：不是关于你的，是关于 AI 助手平时怎么办错事——该问的时候闷头就干、把话写得云里雾里、把没做的事说成做了。这些在文件夹里就是普通文字写着的，跟你手头这事有关的那几条他会看。除此之外，他把你随口给的纠正一条条攒起来——你不用填任何表。

## 你要打的字

最开头打一次：`/start` ——第一次那场中途断了，再打一次也行；他从同一个地方接着走，不会从头来。

后面值得记住的就三个词。照这里写的样子打，前面那根斜杠也要：

| 词 | 干什么的 |
|---|---|
| `/session-save` | 把这次对话存进记忆 |
| `/recall` | 找一条旧记录 |
| `/reflect` | 把这几天出的岔子过一遍——等你聊过几次以后，他还会说说自己摸到了你的哪些脾气、还有什么不知道 |

别的都用大白话：“把这次对话存一下”、“找找我在哪写过……”、“把我为什么这么定记一笔”、“以后答得短点”。整理记忆和复盘岔子他都自己开口——你只要说“好”或者“回头再说”。你想自己开口叫他复盘，那个词是 `/reflect`。

每个词怎么用（一步一步、带例子）、文件夹里有什么，见说明：你文件夹里的 `docs/zh/guide.md`，或在线 https://xcota.github.io/pos/zh/guide.html 。

## 你的东西

都在你自己的硬盘上，就在那一个文件夹里，是普通的文字文件——最简单的记事本一类的小软件都打得开。没有什么专门存东西的软件，网上也没有我们的机器替你保管。我们不给你注册任何东西：我们这边没有账号，也没地方开。唯一一个会自己在旁边待着的，是你电脑里那个搜索，前提是你开了它——它为你的问题醒一下，半个钟头后又睡回去，都在你自己的机器上。

你的记录只住在那个文件夹里：把它整个拷一份，记录就搬到另一台电脑上了。另外，Claude Code 自己会在文件夹外面、在它自己的地盘上留一份对话本身的记录——删你的文件夹删不掉那些，它们跟 Claude Code 自己的文件一起走。

密码、支付密码、密钥（给程序用的那种一长串钥匙）、卡号、安全码、短信验证码、钱包助记词、身份证号：这些你从来不需要给；文件夹里有一条规矩，禁止把它们中的任何一样写进任何文件——就算你自己念出来、还让他存也不行。只记事情，不记秘密：写“有银行的权限”这种就行，密码本身不写。要是某个文件里已经躺着一个，他会告诉你，而不是闷声把它改掉。

关于联网，说句实在的：助手要回你话，你记录里的片段就会发到 Claude 那边——跟你打进任何 AI 聊天框里的字一样。东西存在你这边，动脑子那部分在 Anthropic 那边的机器上，所以你聊的时候得连着网。别处一概不发：搜索、还有核对他引用的话对不对，都在你自己的机器上做。整理记忆是助手自己做的，所以那些记录也跟你写给他的别的东西一样，会发到 Claude。

硬盘占多少——而且只有你答应了按意思搜索才占：总共大概一个 G，下载一次。一部分在你的文件夹里，一部分在系统藏起来的下载文件夹里——助手能把两处都指给你看，也能删掉。两处都不是你的记录，而且以后重新弄一遍，一条记录都不会少。

## 常见问题

**多少钱？** 你得有 Anthropic 的 Claude 订阅——助手在那儿干活。Pro 是便宜的那档，开头够用；在 Anthropic 自己的官网上买。订阅有个用量上限：用到头，助手停几个钟头，然后又能用。没有别的费用，也不用付给我们任何钱。

**手机上能用吗？** 不能。要电脑：Mac 或 Linux。Windows 目前还不行——没有这个版本，白搭一晚上。

**我把文件夹删了会怎样？** 你的记录就没了，关于你的事他一样都不记得；别处没有第二份。有两样住在文件夹外面，不受影响：一是对话本身的记录，Claude Code 存在它自己的地盘上（它跟 Claude Code 自己的文件一起走）；二是按意思搜索下载的那本词典，如果你当初答应了的话——那不是你的记录，但占地方。

**可以用英文或者中文写吗？** 可以——你用什么语言写，他就用什么语言说。他猜不出你想用哪个的时候，会问你一次。

**第一次那场一定要走完吗？** 不用。第一遍给你一个能开工的底子，剩下的边用边补，在平常聊天里补。任何一个问题上都能停，父母和小时候可以整段跳过。

**他会记我什么？怎么擦掉？** 你讲过的东西，加上他自己的结论，而且结论标着是他的猜测。全都是文件，你可以打开、看、改、自己手动删——或者干脆跟他说：这条去掉。你自己改过或者划掉的一行，就一直是你改后的样子。

**他会给我下诊断吗？** 他做的是画像：反复出现的反应——亲近的人疏远时你怎么做，失败以后你把责怪往哪放，压力大了你会变成什么样——以及这些是打哪来的，包括家里，如果你聊到的话。这不是心理治疗：没有练习，没有作业，也没有“这块你该改改”。画像在你手上，你自己看、自己改。你说不想要，他就不往下挖。

**他的记忆要我自己收拾吗？** 不用。每次开头他都自己看一遍自己的记录，聊完你说一句“存一下”。整理记忆和复盘岔子他自己会提，两样都等你点头。你说“不”也不会坏什么。你存对话的时候他会再问一次，下次打开再问一次，直到你说“好”。

**要是坏了呢？** 用大白话跟他说你屏幕上看到了什么。他看的是同一个文件夹，自己就能修。最坏的情况：把旧文件夹挪到一边——你的记录还在里头——重新解压一份新的，助手能把你的记录搬过去。

## 需要什么：老实列一列

- 一台 Mac 或者 Linux 电脑。Windows 目前还不行——没有这个版本，白搭一晚上。
- Anthropic 的 Claude 付费订阅，Pro 或 Max——唯一要花的钱。Pro 开头够用。
- Claude Code 这个程序，装一次。
- 两个不要钱的小程序：Python 和 Git。不用你自己去查：第一次打开的时候，助手会用大白话告诉你缺不缺东西，再给你一行字粘上去——就这么点事。没有 Python，少三样：按意思搜索没有了；“他塞给你的话到底是不是你说的”这道核对也没有了（这时候那几行干脆不放进卡片，而不是瞎猜）；你那些记录之间的链接还通不通，也查不了。没有 Git，就没有旧版本这张安全网。别的什么都不变，不会坏，屏幕上也不会跳错误。
- 这个文件夹，下载下来解开，放哪儿随你。
- 在那个终端窗口里打两行字；以后每次回来还是这两行，没别的。
- 跟助手聊天的全程要连着网。
- 第一次大概十五分钟；更深的东西以后在平常聊天里慢慢攒。
- **一个“要不要”的问题：** 按意思搜索——硬盘上大概一个 G，下载一次，五到十分钟。有了它，他按你问题的意思找你的记录，不用一模一样的词。说“不要”就什么都不下载，别的照常。

**不**需要的：不用编程、不用在别处注册账号、不用自己弄服务器那种东西。
