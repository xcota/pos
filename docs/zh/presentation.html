Camomile（洋甘菊）

你电脑里的一个文件夹。在这里，AI 助手记得你：你在忙什么、你做过什么决定、该用什么方式跟你说话。

2026 年 9 月版 · AGPL v3

这是什么

Camomile（洋甘菊）是你电脑里的一个文件夹，加上一个会读写这个文件夹的 AI 助手。

平常的 AI 聊天，每次都从零开始：你是谁、在忙什么、已经定了什么。在这里，这些都躺在你硬盘上的文件里。助手在聊天开头看一眼，在结尾添几笔。用得越久他越说得准——不是因为他“变聪明了”，而是因为关于你的记录更多了，而且是用你自己的话记的。

名字来自一幅画：你在中间，周围七片花瓣，每一片是生活的一个方面。

  • 自我成长（学习与成长） —— 你在学什么、往哪儿长
  • 活力（身体与精力） —— 身体、睡眠、精神头
  • 环境（身边的人和住的地方） —— 家人、朋友、伙伴，还有你住的地方
  • 财富（对你来说什么是够） —— 多少算够，你怎么知道够了
  • 休息（什么让你恢复） —— 你靠什么缓过来、靠什么高兴
  • 事业（你在做什么） —— 工作、项目，你真正花力气在做的事
  • 资产（钱和财产） —— 收入、存的钱、房子、东西、欠的钱

在你的文件里，这七个方面用的是拉丁字母的名字（samorazvitie、vitalnost 这一类）。那只是文件名，不用管。

花瓣的意思很简单：日子不是只有一片。助手七个方面都记，时间一长就看得出哪片写得满、哪片你压根没提过。

怎么运作

整套东西就三样。

1. 记忆——他在两次对话之间记得你

没有什么玄的。文件夹里是普通的文本文件：“我是谁”、“我现在在忙什么”、“我的目标”、每天的记录、关于人和项目的卡片。每次对话一开始，助手把这些文件读一遍，几秒钟的事。结尾你说 /session-save（或者干脆说“把这次对话存一下”），他就把做了什么、定了什么添进去。

就这样。没有魔法，也没有数据库：用记事本打开文件，你看到的就是普通文字，你自己也能改。

还有一样叫按意思搜索——你问“我在哪说过早上没力气”，记录里写的是“起床像散架了”，他也能找到。这个东西不会偷偷装上：刚认识的时候助手会问你一个“要不要”的问题，并老实说要付出什么——硬盘上大概一个 G，下载大概五到十分钟。你说“不要”，就什么都不下载，搜索改成按原词找，别的照常。万一没装成（有时会），也不会坏，他会用一行字告诉你，然后接着往下走。

2. 事情——他帮你盯着项目和决定

助手会给你每件事单开一页，页与页之间用链接连起来——像一本关于你自己生活的小百科。人、项目、决定、看过的材料，各有各的卡片。

碰上不好拿的主意，可以让他单独记一笔：定了什么、为什么这么定。半年后再问“我当时怎么想的”，有答案，不用猜。

3. 镜子——他会发现你的习惯，然后跟着调

这是平常的聊天没有的。你纠正他——“太长了”、“别一次问两个问题”、“叫我名字就行”——这条纠正会记进“我是谁”这个文件里的“怎么跟我打交道”那一段，而这个文件他每次启动都会重读。所以你今天关了窗口、明天开个新的，他的说话方式不会跑回原样。

而且他不是闷声记的：你在结尾说“存一下”的时候，他会把一两条备选的句子摆出来，只写你点头的那几条。你没吭声，他就不写。反过来也一样：关于说话方式的纠正只算说话方式，不会被当成对你这个人的结论。

隔几天你可以打 /reflect，他会把最近几天的活儿过一遍，挑出教训。

说句实在的：文件夹里本来就带着四十多条整理好的常见毛病和一套规矩——不是关于你的，是关于 AI 助手平时怎么犯浑的（该问清楚的时候闷头就干、把话写得云里雾里、把没做的事说成做了）。也就是说，他来的时候已经被管教过一轮，剩下的你接着管。

怎么开始

下面是屏幕上会看到什么，一步一步来。跟 README 里是同样的四步，没有别的。

第 1 步：装 Claude Code。 Claude Code 是 Anthropic 公司的程序：它在终端（输入命令的窗口）里跑，你也就在这个窗口里跟助手来回打字，跟平常聊天一样。在这个程序里，他才有权限读写你文件夹里的文件。要有付费的 Claude 订阅（Pro 或 Max），钱付给 Anthropic。说明在这里：https://code.claude.com/docs/en/setup ——上面有一行命令，粘到终端里就行（第 3 步）。只装一次。

第 2 步：下载文件夹并解开——比如放到“文稿”里。地址：https://gitee.com/cotya/pos-starter （点“克隆/下载”→“下载 ZIP”）。也可以用 https://github.com/xcota/pos （绿色的“Code”按钮 →“Download ZIP”），不过在国内 GitHub 常常打不开。压缩包（ZIP 文件）解开后的文件夹叫 pos-starter-master 或者 pos-main，可以改名叫 Camomile。

第 3 步：在 Claude Code 里打开这个文件夹。 要用到打命令的那个窗口（Mac 上叫“终端”，用电脑的搜索就能找到）。在那里打两行。第一行：cd，空格，然后用鼠标把文件夹拖进来，回车。cd 的意思是“进到某个文件夹”：你在告诉窗口，接下来跟哪个文件夹打交道。拖进来之后会自己冒出一长串带斜杠的字，那是文件夹的地址，本来就该这样，不用改。第二行：claude，回车。第一次打开时，程序会问你是否信任这个文件夹里的文件——选“是”，这是你自己的文件夹。要是回你 command not found，说明程序没装上，回到第 1 步。

成功是什么样。 窗口清空，出现程序的问候语，下面有一行可以打字。好了，接下来就是普通的来回：打一句，回车，看回话。

第 4 步：打 /start。 一个词。从这儿开始由助手带着走。

明天怎么回来。 还是那个窗口、那两行：cd 加文件夹，然后 claude。键盘上的向上箭头会把你上次打的字调出来。还有件事先说好：见面流程的最后，助手会请你关掉他再重新打开一次——就是这两行。 另外，每隔几天，聊天一开始他会说“我的记忆要整理几分钟，现在做吗？”——答“好”就行；不问你，他不会自己动手。

第一次：见面

助手会问你话——就是普通聊天，一次一个问题，不是十页的问卷。

现在是这么走的：

  • 开头。 他问你想让他怎么称呼你，用一段话说清楚接下来会发生什么。然后一个“要不要”的问题：装不装按意思搜索，并当场说清代价（硬盘大概一个 G，五到十分钟）。他不会闷声下载任何东西。
  • 三段讲述，不是问卷。 一次都不用给自己打分：昨天一天，从起床到睡觉；这一个月——买了什么、后悔什么、高兴什么；这一年学到了什么、跟谁学的。这些就够把七个方面都覆盖到。你讲的话会一字不动地存下来。
  • 每个方面一张卡片，给你过目。 带编号的几行：「你说」（只有你的原话，而且跟你讲过的话核对过）、「我在你的文件里看到」、「我觉得」，然后是「我不知道」和「我听到的是『…』——对吗？」，最后一行是他打的分加上他有多大把握。你按编号改。某个方面你几乎没提，那就干脆没有分——“这个你没说过”。
  • 往深里问。 过了五个方面，问题会换个路数：什么事是真的让你火大，你失去过什么、到现在没消化，一个人待着和孤独有什么不一样，对你来说什么是回不了头的。这不是测试，还是聊天，只是不停在表面。
  • 关于父母和童年是单独的一段，而且看你愿不愿意。不想聊就直说，流程照样往下走。
  • 画像。 他从这些里攒出一段描述：你是怎么运转的，强在哪、盲区在哪，遇到事一般怎么决定。至少有两张卡片你看过并且点头或者改过，他才开始搭文件夹——没经你过目的结论，他不拿来用。
  • 搭文件夹。 然后他把你的文件夹搭起来：“我是谁”这个文件、你的目标、开头几件事、一张七个方面的总览。最后请你关掉他再重新打开一次。

要多久。想快点开工，十五分钟左右。全走完、连往深里问的那些，就明显长了，得分几次。随时可以停：该写的都写下来了，回来打 /start 接着走。

用起来以后，有什么不一样

存下来的对话越多，你要重复讲的就越少：你在做什么、搁下了什么、身边有谁，助手都拿着。旧的决定一句话就能找回来。“怎么跟我打交道”那一段会被你自己的纠正喂大——聊起来就比第一天准。我们不给期限：快慢只取决于你讲了多少、存了多少。

不会发生的事：助手不会自己先来找你说话，不会提醒你办事，你不开口他什么都不做。他不排日程，也不盯着你。只有你打开对话、开口要，事情才发生。值得记住的就三个词（用英文字母打，前面带斜杠）：/session-save 把对话存进记忆，/recall 找旧东西，/reflect 复盘这几天的岔子。用大白话说也行：“把这次对话存一下”、“找找我在哪写过……”。

常见问题

我的东西存在哪？

在你的硬盘上，就在这个文件夹里，是普通的文本文件。没有另外的存储，也没有我们的服务器。我们不给你注册任何东西：我们这边没有账号，也没地方注册——要订阅的只有 Anthropic 那边，为的是 Claude Code 这个程序。

密码呢？

密码、密钥、银行卡号不用给助手，就算你在聊天里说出来，他也不会写进你的文件——这写在他的规矩里。

有东西发到网上吗？

有，这点得说明白。助手要回你话，你记录里的片段就会发到 Claude 那边——跟你写进任何 AI 聊天里的文字一样。不会发给别的任何一家，但要说“所有东西都留在你电脑上”，那就是假话。

多少钱？

要有 Anthropic 的 Claude 付费订阅（Pro 或 Max）——助手在那儿干活，钱付给 Anthropic。除此之外没有别的费用，也不用付给我们任何钱。

手机上能用吗？

不能。要电脑：Mac 或 Linux。Windows 目前用不了。

我把文件夹删了会怎样？

你的记录就没了：助手不再记得你任何事，别处也没有备份。文件夹之外只剩下按意思搜索用的那个词典（如果你当初同意装），大概一个 G；那不是你的东西，但占地方。反过来说也一样：把文件夹拷一份，你的记录就整个搬到另一台电脑上了。

可以用中文或者英文吗？

聊天可以，助手听得懂也会用你写的语言回你。见面时的那些问题现在有中文。

见面流程一定要走完吗？

不用。第一次就够开工了，剩下的边用边补。任何一个问题上都能停，关于父母和童年那段可以完全跳过。

助手会记我什么？怎么清掉？

你讲过的东西，加上他自己的结论。这些都是文件，你可以打开、读、改、手动删掉。或者直接跟他说：这条去掉。

他会给我下诊断吗？

他会做一个心理画像：注意你反复出现的反应——亲近的人疏远时你怎么做，失败以后你把责怪往哪放，压力大了你会变成什么样——以及这些是打哪来的，包括家里，如果你聊到的话。他不会当面给你贴标签，但结论会写进你的“我是谁”文件。画像在你手上，你自己看、自己改。你不想要，跟他说一声，他就不往下挖。

助手不做什么？

不会自己先开口，不会提醒，不按日程干活，不会没经你同意就用你的名义上网，不会替你给任何人发东西，也不会把没做的事说成做了——他没做到或者没把握的，会直说。

要是坏了呢？

用话跟他说你屏幕上看到了什么。他读的是同一个文件夹，自己就能修。最坏的情况：把文件夹重新解开一次，再走一遍见面流程。

需要什么：老实列一列

  • 一台 Mac 或 Linux 电脑。Windows 目前用不了。
  • Anthropic 的 Claude 付费订阅（Pro 或 Max）。
  • 装好的 Claude Code 程序。
  • 两个免费的后台小程序：Python 和 Git。Mac 上通常本来就有。没有 Python 就没有按意思搜索、也不核对引用（那样「你说」那几行他就干脆不显示）——但不会坏，屏幕上也不会跳错误。
  • 会在终端里打两行字——而且每次回来都照打一遍。
  • 跟助手聊天全程要联网。
  • 第一次大概十五分钟。往深里走，得分几次。
  • 一个“要不要”的问题：按意思搜索。助手一开头就问，并说清代价：硬盘大概一个 G，五到十分钟。有了它，你能按问题的意思找回自己的记录，而不是靠一模一样的词。说“不要”就什么都不下载，别的照常。
  • 看你需要：看 YouTube 视频并整理。那要另外装一个免费的小下载程序。没有它，聊天记录、笔记、摘要照样能整理。

不需要的：不用编程、不用懂英文、不用在别处注册账号、不用自己搭服务器。
